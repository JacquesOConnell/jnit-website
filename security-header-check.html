HTTP security header check.

Paste a website’s response headers to review common browser protections. Analysis happens entirely in your browser.

Windows PowerShellcurl.exe -I https://example.com
macOS or Linuxcurl -I https://example.com

Why paste the headers?

A browser cannot freely read another website’s response headers because of cross-origin security controls. A live URL checker will require a small server-side service when deployed.

    Headers must fit the application.

    CSPControl content sources

    A restrictive policy can reduce script and content-injection risk but must be tested carefully.

    HSTSRequire HTTPS

    Tells compatible browsers to use secure connections for a defined period.

    FramingLimit embedding

    Helps prevent untrusted sites from placing pages inside deceptive frames.
