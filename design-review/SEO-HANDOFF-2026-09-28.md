## What changed

- Specific titles and descriptions for the main commercial pages and all individual tool pages. The visible Services, Websites and Applications headings now state the work JNIT does.
- `WebSite` and `Organization` JSON-LD on the home page using only published JNIT business details. No address, reviews, awards or opening hours were invented.
- Dedicated, indexable pages for the backup storage calculator, website launch checklist and password generator. They retain the existing tool controls and calculations while adding practical explanations and limitations. The toolkit links to them directly.
- The generic quick-tool shell and the fictional demo sites request `noindex,follow`. Demos remain linked from the Websites portfolio. The sitemap lists the indexable pages only.
- Google Analytics now records `contact_click` for WhatsApp and email links, and `project_brief_open` for clicks into the quote page. These events contain no form text, email address or phone number. A click is an expression of interest, not a confirmed enquiry.
- The updated analytics and shared quick-tool scripts have new version strings so browsers request the current files after upload.

3. Check the Search Console Performance and Page Indexing reports over the following weeks. Use actual search queries to decide which of the remaining 31 hash-driven utility routes merit a dedicated page.
4. In Google Analytics, check that `contact_click` and `project_brief_open` arrive. Treat these as click events; verify real enquiries separately. Set up any Key Events according to your measurement policy.
5. Measure the live mobile pages with PageSpeed Insights after upload. Prioritise any specific Core Web Vitals findings before changing visual assets or scripts.
